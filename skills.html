01 / MG-VOXSTAGE

纸艺拼贴 Skill

把口播稿拆成分镜，延续统一的纸艺拼贴语言，整理图片、视频提示词、封面和发布文案。

查看 GitHub 仓库 ↗

把中文口播的制作步骤整理成一条可复用流程：先拆分镜与提示词，再逐张生成、查看和验收画面，最后根据已完成的图片编写运动提示词。

怎么组织流程

分镜与构图 → 首图确认 → 逐张生图验收 → 视频提示词 → 两版封面与发文

最终交付什么

分镜、生图提示词、静态图片、图生视频提示词、独立的 3:4 与 4:3 封面，以及标题、正文和话题。

使用实体厚纸片、半调人物、前后景与投影建立视觉层次。Skill 默认交付图片与提示词，成片视频由后续流程制作。

02 / xhs-fruit-cards

水果图文 Skill

把水果选题整理成有来源、视觉统一的五页科普图文，从审核、文案到图片和发布包。

查看 GitHub 仓库 ↗

先核验资料与选题可行性，再确定五页内容。视觉延续奶白底、墨绿标题和真实水果摄影，让营养档案、常见误区、吃法与挑洗保存保持清楚的阅读层次。

怎么组织流程

资料核验与选题审核 → 五页文案 → 视觉提示词 → 封面与内页逐张验收 → 发布包

最终交付什么

默认五张 3:4 静态图，以及逐页文案、资料来源、提示词、发布文案和验收记录。

将内容核验、视觉一致性和逐张验收放进同一流程，也支持仅写内容、提示词或对某一页定点修改。

03 / xhs-herbal-cards

药材图文 Skill

围绕药材、食药物质与日常食材，整理有资料依据、表达边界和统一视觉的七页图文。

查看 GitHub 仓库 ↗

支持“草木初识”的单主题和“草木搭配”的双食材主题。先审核内容方向，再分清传统经验、研究证据、适用范围与风险信息，最后进入图文制作。

怎么组织流程

选题与资料 → 可行性审核 → 七页内容 → 逐页提示词 → 生图验收与交付

最终交付什么

默认七张 3:4 静态图，配套审核单、资料来源、逐页文案、提示词、发布文案和验收记录。

暖白、墨绿与浅绿知识卡保持系列感；技术规格检查和实际目视检查分别进行。

WECHAT MINI PROGRAM / 01

早餐人格测试

把日常早餐习惯，做成一份容易参与、也愿意分享的人格小测试。

25 道题 · 9 种早餐人格毛毡 / 针织 / 手作质感微信体验版 · 1.0.6

首页 · 答题页 · 结果页 / 点击图片查看完整界面

01 / BACKGROUND

从一个早餐想法开始

最初的想法很简单：用早餐习惯测一测人格。我想让测试有一点日常感，让结果有一个能被记住的名字、一张有性格的人物形象，也方便分享给朋友。

我先梳理了 25 道题、计分规则和 9 种人格，再逐步补齐一句话点评、基础分析、完整报告与分享海报。页面和人物的制作围绕这条完整的体验展开。

02 / DESIGN CONCEPT

让早餐也有自己的性格

先把亲切感做出来

配色从少女粉、橙色等方向试起，最后收拢到暖奶油色、可可棕与橙色，再用少量蓝绿色提亮。毛毡、针织和手作玩偶的质感贯穿人物与页面，让测试像一份有温度的小礼物。

九种结果，要有九种辨识度

早期人物的脸型、体型和动作过于相似。我重新为每种人格安排脸型、身体比例、站姿、道具和气质，先确认主形象，再整理三视图，让角色差异真正体现在画面里。

先看懂一句，再慢慢读下去

结果先用一句话说出性格特点，再分层展开基础分析与完整报告。人物负责建立印象，文字负责把结果解释清楚。

03 / FEATURES & USE

从答题到分享，接好每一步

  1. 01

    开始与续答

    从首页开始测试；中途退出后，可以继续上次进度。

  2. 02

    完成 25 道题

    真实计分，支持返回修改，并处理快速连点。

  3. 03

    查看并分享结果

    查看主副人格、完整报告，生成并保存分享海报。

结果支持并列主人格与副人格，本地历史可以回看已完成的测试。完整报告最终调整为免费开放；好友分享入口、图片加载失败、数据读取异常和相册权限等状态也纳入了流程。

网页原型用于确认视觉与交互，正式版本使用 WXML、WXSS 和 JavaScript 重新实现。普通文字与点击操作逐步回到原生组件，图片主要承载人物、毛线标题和纹理。

04 / OUTCOME & REFLECTION

从原型，到微信体验版

25道测试题
9种早餐人格
43张主要界面与状态稿
已交付微信体验版

项目记录中的 1.0.6 版本已上传微信体验版，20 项自动测试和 9 个 WXML 模板检查通过。后续仍需要在 iPhone 与安卓真机上完整验收答题、报告、保存和分享，并确认隐私与客服配置。

最值得留下的三件事

  • 先定产品规则。免费还是收费、主体与平台条件，会直接影响页面和功能范围。
  • 先跑通三个原生页面。首页、第一道题和结果页，能尽早暴露布局、图片和组件问题。
  • 素材与验收一起管理。建立素材清单和文件校验，尽早在真机上检查，减少旧稿回流和重复返工。
